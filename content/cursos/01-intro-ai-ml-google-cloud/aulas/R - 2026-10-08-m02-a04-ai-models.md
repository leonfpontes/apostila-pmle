## Conteúdo por tópico

### 1. ⭐ A hierarquia: IA ⊃ ML ⊃ deep learning ⊃ GenAI

A aula abre desfazendo o uso intercambiável de "IA" e "ML". São
**aninhados**, não sinônimos:

```
┌───────────────────────────────────────────────────────┐
│ ARTIFICIAL INTELLIGENCE (AI)                          │
│ termo-guarda-chuva: tudo em que computadores          │
│ imitam a inteligência humana                          │
│ ex.: robôs, carros autônomos                          │
│                                                       │
│   ┌───────────────────────────────────────────────┐   │
│   │ MACHINE LEARNING (ML)                         │   │
│   │ computadores aprendem SEM ser explicitamente  │   │
│   │ programados                                   │   │
│   │ → supervisionado e não supervisionado          │   │
│   │                                               │   │
│   │   ┌───────────────────────────────────────┐   │   │
│   │   │ DEEP LEARNING / DEEP NEURAL NETWORKS  │   │   │
│   │   │ acrescenta CAMADAS entre os dados de  │   │   │
│   │   │ entrada e os resultados de saída,     │   │   │
│   │   │ para a máquina aprender em            │   │   │
│   │   │ profundidade                          │   │   │
│   │   │                                       │   │   │
│   │   │   ┌───────────────────────────────┐   │   │   │
│   │   │   │ LLMs → GENERATIVE AI (GenAI)  │   │   │   │
│   │   │   │ cria conteúdo e executa       │   │   │   │
│   │   │   │ tarefas a partir de pedidos   │   │   │   │
│   │   │   └───────────────────────────────┘   │   │   │
│   │   └───────────────────────────────────────┘   │   │
│   └───────────────────────────────────────────────┘   │
└───────────────────────────────────────────────────────┘
```

As definições exatas:

| Termo | Definição da aula |
|---|---|
| **Artificial intelligence (AI)** | *Umbrella term* que inclui **qualquer coisa** relacionada a computadores **imitando a inteligência humana**. Exemplos: robôs, carros autônomos |
| **Machine learning (ML)** | **Subconjunto** da IA que permite aos computadores **aprender sem serem explicitamente programados** — em contraste com a **programação tradicional**, em que se diz explicitamente ao computador o que fazer. Inclui principalmente **supervisionado** e **não supervisionado** |
| **Deep learning / deep neural networks** | **Subconjunto do ML** que acrescenta **camadas** entre os dados de entrada e os resultados de saída, para a máquina aprender **em profundidade** |
| **Generative AI (GenAI)** | **Cria conteúdo e executa tarefas a partir de pedidos**. Usa **foundation models** como os **LLMs** — *um tipo de modelo de deep learning* — para **prever, interpretar e interagir com linguagem** |

📌 **A frase que a prova mais provavelmente testa:** um **LLM é um tipo de
modelo de deep learning**. Logo, GenAI está *dentro* de deep learning, que
está dentro de ML, que está dentro de IA.

📌 **O contraste que define o ML:** aprender **sem ser explicitamente
programado**, contra a **programação tradicional** em que se diz ao
computador exatamente o que fazer.

### 2. ⭐ Supervisionado × não supervisionado — os dois problemas

A aula ensina pela história, com dois problemas:

| | **Problema 1** | **Problema 2** |
|---|---|---|
| **Tarefa** | classificar **cães e gatos** num conjunto grande de fotos | classificar **raças de cães** |
| **A situação** | você **já sabe** a diferença, então **rotula** cada foto e passa as fotos rotuladas à máquina | você **não conhece** muitas raças e **não consegue rotular**; manda as fotos **sem rótulo** |
| **O que a máquina faz** | aprende dos dados **com as respostas** (os rótulos) e passa a dizer se uma foto nova é cão ou gato | aprende dos dados **sem as respostas** e encontra **padrões subjacentes** para agrupar os animais |
| **É** | **supervised learning** | **unsupervised learning** |

### 3. ⭐ A tabela de três colunas (decore literalmente)

| | **Supervised** | **Unsupervised** |
|---|---|---|
| **Dados** | **rotulados** (*labeled*) | **não rotulados** (*unlabeled*) |
| **Direção** | **task-driven** (dirigido pela tarefa) | **data-driven** (dirigido pelos dados) |
| **Identifica** | **uma meta** (*a goal*) | **um padrão** (*a pattern*) |

> 💡 **O teste rápido da aula:** o supervisionado **dá a cada ponto de dado
> um rótulo ou uma resposta**; o não supervisionado **não dá**.

📌 O par **task-driven × data-driven** é fácil de inverter sob pressão. Um
jeito de fixar: no supervisionado você já sabe **qual é a tarefa** (a meta
existe antes); no não supervisionado você só tem **os dados** e deixa o
padrão aparecer.

### 4. ⭐ Os cinco tipos de problema e seus modelos

Esta é a tabela mais cobrável da aula. **Dois** tipos de supervisionado e
**três** de não supervisionado:

| Aprendizado | Tipo | O que prevê / faz | Exemplo da aula | Modelo / técnica |
|---|---|---|---|---|
| **Supervisionado** | **Classification** | prevê uma variável **categórica** | a foto mostra um gato ou um cão? | **logistic regression** |
| **Supervisionado** | **Regression** | prevê uma variável **numérica** | prever vendas de um produto a partir das vendas passadas | **linear regression** |
| **Não supervisionado** | **Clustering** | **agrupa** pontos com características similares em *clusters* | usar dados demográficos para achar **segmentação de clientes** | **k-means clustering** |
| **Não supervisionado** | **Association** | identifica **relações subjacentes** | correlação entre dois produtos, para colocá-los mais perto no supermercado numa promoção | **regras de associação**, algoritmo **Apriori** |
| **Não supervisionado** | **Dimensionality reduction** | **reduz o número de dimensões/features** para melhorar a **eficiência** do modelo | combinar idade, histórico de infrações e tipo de carro numa regra simplificada de cotação de seguro | **principal component analysis (PCA)** |

> ⚠️ **A PEGADINHA CENTRAL DA AULA — e a mais clássica de ML inteiro:**
>
> | Modelo | Resolve |
> |---|---|
> | **Logistic** regression | **CLASSIFICAÇÃO** (categórica) |
> | **Linear** regression | **REGRESSÃO** (numérica) |
>
> A "logistic **regression**" tem "regressão" no nome mas **não** resolve
> problemas de regressão. A própria aula sublinha: *"a logistic regression
> model is for classification problems, while a linear regression model is
> for regression problems."*
>
> 📌 Mnemônico: **L**inear → números (**L**inha numérica). **Logistic** →
> **lo**gica binária, categorias.

📌 Mnemônico para contar: supervisionado tem **2** (classificação,
regressão); não supervisionado tem **3** (clustering, associação, redução
de dimensionalidade). **2 e 3.**

### 5. Os dois exercícios guiados da aula

A aula resolve dois cenários em voz alta, sempre na mesma sequência de três
perguntas: **(a)** supervisionado ou não? **(b)** qual tipo de problema?
**(c)** qual modelo? Vale treinar nessa ordem.

**Cenário 1 — prever o gasto do cliente a partir do histórico de compras**

| Pergunta | Resposta | Por quê |
|---|---|---|
| Supervisionado ou não? | **Supervisionado** | você **tem o dado rotulado**: o valor que os clientes já gastaram |
| Classificação ou regressão? | **Regressão** | prevê um **número contínuo** (gasto futuro) |
| Qual modelo? | **Linear regression** | logística é para classificação; linear é para regressão |

**Cenário 2 — identificar segmentação de clientes, com o mesmo conjunto de
dados**

A aula acrescenta um detalhe relevante: *"you don't want to base your
judgment on stereotypes such as age or gender"* — não se quer decidir por
estereótipos, então se pede ao computador que descubra o padrão.

| Pergunta | Resposta | Por quê |
|---|---|---|
| Supervisionado ou não? | **Não supervisionado** | **nenhum cliente está rotulado** como pertencente a um segmento |
| Clustering, associação ou redução de dimensionalidade? | **Clustering** | segmentação de clientes **é** um problema de agrupamento |
| Qual modelo? | **k-means clustering** | não é caso de logística nem de linear |

📌 **Detalhe importante:** os **dois cenários usam o mesmo conjunto de
dados**. O que muda o tipo de aprendizado **não é o dado, é a pergunta** —
se existe rótulo para o que você quer prever. Isso é exatamente o tipo de
nuance que uma questão bem feita explora.

## Glossário da aula

- **Artificial intelligence (AI)** — termo-guarda-chuva para tudo em que
  computadores imitam a inteligência humana (robôs, carros autônomos).
- **Machine learning (ML)** — subconjunto da IA; o computador **aprende sem
  ser explicitamente programado**.
- **Programação tradicional** — o oposto do ML: diz-se explicitamente ao
  computador o que fazer.
- **Deep learning / deep neural network** — subconjunto do ML que
  acrescenta **camadas** entre entrada e saída para aprender em
  profundidade.
- **Large language model (LLM)** — **um tipo de modelo de deep learning**;
  prevê, interpreta e interage com linguagem.
- **Foundation model** — modelo base que a GenAI usa; os LLMs são um
  exemplo.
- **Generative AI (GenAI)** — cria conteúdo e executa tarefas a partir de
  pedidos.
- **Supervised learning** — aprende de dados **rotulados**; é
  **task-driven**; identifica **uma meta**.
- **Unsupervised learning** — aprende de dados **não rotulados**; é
  **data-driven**; identifica **um padrão**.
- **Label (rótulo)** — a resposta associada a cada ponto de dado; é o que
  existe no supervisionado e falta no não supervisionado.
- **Classification** — supervisionado; prevê variável **categórica**.
  Modelo: **logistic regression**.
- **Regression** — supervisionado; prevê variável **numérica**. Modelo:
  **linear regression**.
- **Logistic regression** — modelo para **classificação** (apesar do nome).
- **Linear regression** — modelo para **regressão**.
- **Clustering** — não supervisionado; agrupa pontos similares em clusters.
  Modelo: **k-means**.
- **k-means clustering** — algoritmo de agrupamento.
- **Association** — não supervisionado; acha **relações subjacentes** entre
  itens. Técnica: **regras de associação**; algoritmo **Apriori**.
- **Apriori** — algoritmo de regras de associação.
- **Dimensionality reduction** — não supervisionado; reduz o número de
  **dimensões/features** para melhorar a **eficiência** do modelo.
- **Principal component analysis (PCA)** — técnica de redução de
  dimensionalidade.
- **Feature** — característica/variável de entrada do modelo.
- **Customer segmentation** — caso de uso típico de **clustering**.

## Questões estilo prova

**1.** Uma seguradora quer simplificar a cotação combinando idade,
histórico de infrações e tipo de carro em um número menor de variáveis, para
deixar o modelo mais eficiente. Que tipo de problema é esse?

- A) Clustering
- B) Association
- C) Dimensionality reduction
- D) Regression

<details><summary>Gabarito</summary>

**C — dimensionality reduction.** É literalmente o exemplo da aula:
**reduzir o número de dimensões/features para melhorar a eficiência** do
modelo. A técnica citada é **PCA**. (A) agruparia clientes; (B) buscaria
relações entre itens; (D) é supervisionado e preveria um número.
</details>

**2.** Um time precisa prever se um e-mail é spam ou não. Qual modelo a aula
indicaria?

- A) Linear regression
- B) Logistic regression
- C) k-means clustering
- D) Principal component analysis

<details><summary>Gabarito</summary>

**B — logistic regression.** "Spam ou não" é uma variável **categórica**,
logo é **classificação**, e classificação usa **logistic regression**.
A pegadinha é (A): a palavra "regression" aparece nos dois nomes, mas
**linear** é para prever **números**. Guarde a frase da aula: *"a logistic
regression model is for classification problems, while a linear regression
model is for regression problems."*
</details>

**3.** Associe cada afirmação ao tipo de aprendizado:
*(i)* é task-driven · *(ii)* identifica um padrão · *(iii)* trabalha com
dados rotulados · *(iv)* é data-driven · *(v)* identifica uma meta ·
*(vi)* trabalha com dados não rotulados.

<details><summary>Gabarito</summary>

**Supervisionado:** (i) task-driven · (iii) dados rotulados · (v)
identifica uma meta.
**Não supervisionado:** (ii) identifica um padrão · (iv) data-driven ·
(vi) dados não rotulados.
</details>

**4.** Um varejista tem o histórico de compras dos clientes e quer
descobrir grupos de comportamento semelhante, **sem** partir de categorias
pré-definidas. Qual a combinação correta?

- A) Supervisionado · classificação · logistic regression
- B) Supervisionado · regressão · linear regression
- C) Não supervisionado · clustering · k-means
- D) Não supervisionado · associação · Apriori

<details><summary>Gabarito</summary>

**C.** Não há rótulo dizendo a que grupo cada cliente pertence, então é
**não supervisionado**; descobrir **grupos** é **clustering**; o modelo é
**k-means**. É o Cenário 2 da própria aula. (D) erraria o tipo:
associação busca relação **entre itens**, não agrupamento de clientes.
</details>

**5.** Qual destas afirmações é **falsa**?

- A) Deep learning é um subconjunto de machine learning
- B) Um LLM é um tipo de modelo de deep learning
- C) Machine learning é um subconjunto de inteligência artificial
- D) Inteligência artificial é um subconjunto de machine learning

<details><summary>Gabarito</summary>

**D é falsa** — a relação é o inverso: **IA ⊃ ML ⊃ deep learning**. A IA é
o termo-guarda-chuva, o mais amplo de todos.
</details>

**6.** O que distingue machine learning da programação tradicional?

<details><summary>Gabarito</summary>

No **ML** o computador **aprende sem ser explicitamente programado**; na
**programação tradicional** diz-se a ele **explicitamente o que fazer**.
</details>

**7.** Dois analistas usam **o mesmo conjunto de dados** de clientes. Um
quer prever o gasto futuro; o outro quer descobrir segmentos. Os dois
problemas são do mesmo tipo de aprendizado?

<details><summary>Gabarito</summary>

**Não.** Prever o gasto futuro é **supervisionado** (existe o rótulo: o
valor já gasto) e **de regressão** (número contínuo → *linear regression*).
Descobrir segmentos é **não supervisionado** (nenhum cliente vem rotulado
com seu segmento) e de **clustering** (→ *k-means*). O que define o tipo
**não é o dado, é a pergunta** — se existe rótulo para o que se quer
prever.
</details>
