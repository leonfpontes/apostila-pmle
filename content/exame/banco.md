## Gabaritos corrigidos

Nestas o arquivo original marca uma resposta que a revisão considera errada. Vale ler a explicação com atenção, porque são boas pegadinhas.

| Questão | Arquivo | Revisado | Por quê |
|---|---|---|---|
| Q18 (1.3) | D | C | O gabarito D está errado: o AutoML Tables permite indicar uma coluna como Time column, e então faz o split cronológico automaticamente, reservando dados mais recentes para validação e teste. A opção D faz manualmente o que o AutoML já resolve e com intervalos de 30 dias arbitrários; a opção B ignora a ordem temporal e causaria leakage. |
| Q86 (5.3) | B | D | Vertex ML Metadata é o serviço gerenciado para rastrear artefatos, execuções e linhagem, garantindo reprodutibilidade. O gabarito B (Hive Metastore) está errado: ele guarda metadados de tabelas Hive, não metadados de ML; operations suite e BigQuery (A, C) também não são feitos para isso. |
| Q130 (4.2) | C | B | Carregar o modelo diretamente no job Dataflow (por exemplo, via RunInference) elimina a chamada de rede a um serviço externo, o que dá a menor latência possível de serving. O gabarito C (endpoint do Vertex AI) é tentador por ser gerenciado, mas cada predição adiciona um round-trip HTTP; Cloud Run e GKE têm o mesmo problema. Esta é a resposta do conjunto de questões de exemplo do Google. |
| Q167 (1.1) | B | C | O BigQuery ML já faz one-hot encoding automático de colunas STRING no CREATE MODEL, e esse pré-processamento vai junto no modelo exportado, então basta selecionar as features: é o caminho mais rápido. Em B, aplicar ML.ONE_HOT_ENCODER fora do TRANSFORM obriga a replicar o encoding no serving, o que gera risco de skew e mais trabalho; por isso discordo do gabarito. A funciona, mas é passo desnecessário. |
| Q171 (4.2) | D | B | Questão duplicada da anterior. Os prebuilt containers de scikit-learn não usam GPU, então GPU por réplica (D) só aumenta custo sem ganho; a resposta correta é autoscaling com max 100 réplicas em CPU (B). O gabarito D contraria o requisito de minimizar custo. |

## Como usar

- Leia o enunciado, decida a resposta e só então abra o bloco verde.
- Ao errar, anote o conceito do rodapé da resposta: os erros repetidos mostram o que revisar.
- Muitas questões usam nomes antigos (AI Platform, Cloud ML Engine). A explicação traz o nome atual; na prova vale o raciocínio, não o nome.
- O simulador interativo (https://claude.ai/artifact/3W3WQvvz7danLX4VBWHT1n) sorteia questões por seção ou curso e marca acertos.
